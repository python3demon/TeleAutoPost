## Что умеет бот? 
Это инструмент для удобной подготовки, предпросмотра и автоматической публикации контента в Telegram-каналы для личного использования, поэтому он умеет:
* 📝 **Интерактивный предпросмотр:** принимает текст будущих публикаций и показывает, как именно пост будет выглядеть в канале до его реальной отправки.
* ⚡︎ **Публикация в один клик:** мгновенно отправляет утвержденный пост в целевой Telegram-канал через удобные инлайн-кнопки управления.
* 🕮 **Форматирование без потерь:** сохраняет HTML разметку, абзацы и структуру оригинального текста при пересылке.
* 💾 **Система черновиков:** позволяет сохранять подготовленный пост во внутреннее хранилище, чтобы опубликовать или удалить его позже.
* 📁 **Интуитивное управление:** выводит весь список сохраненных черновиков в виде интерактивной inline-колонны для быстрого просмотра и взаимодействия.

## Использование
Чтобы начать использовать бота, нужно:
1. [Пройти шаги установки](#установка)
2. Добавить бота в свой Telegram-канал и сделать его администратором (с правом публикации постов).
3. Запустить бота в личных сообщениях командой `/start`.
4. Указать ID или юзернейм вашего канала, который запросит бот.

## Установка
```bash
# Клонирование репозитория и переход в директорию
git clone https://github.com/python3demon/TeleAutoPost.git && cd TeleAutoPost

# Настройка конфигурации (укажите ваш токен)
cp .env.example .env
micro .env

# Ставим виртуальное окружение и активируем
python3 -m venv venv
source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Запуск приложения
python main.py
```
